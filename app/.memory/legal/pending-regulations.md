# Pending Regulations

Legal instruments that are expected but not yet effective.
When an instrument becomes effective, move it to `governing-instruments.md` and update rules.

---

## Tracking Format

| Symbol | Expected Name | Type | Expected Effective | Status | Impact |
|--------|--------------|------|-------------------|--------|--------|
| (none tracked) | — | — | — | — | — |

---

## How to Add a Pending Regulation

When a new law/decree/circular is announced:
1. Add a row to this table with expected effective date
2. Add `effectiveFrom` placeholder rule in `procurementRules.ts` (disabled until date arrives)
3. Note which existing rules it will supersede
4. Add ADR if it changes architecture (threshold changes, new instrument type, etc.)

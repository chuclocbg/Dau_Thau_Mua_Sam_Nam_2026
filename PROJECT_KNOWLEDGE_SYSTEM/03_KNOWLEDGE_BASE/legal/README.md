# Legal

**Purpose:** The exhaustive, ranked reference for every legal instrument governing this
system's domain — the *reference content* companion to the *rule* stated in
[`../../01_PROJECT_DOCS/CONSTITUTION.md`](../../01_PROJECT_DOCS/CONSTITUTION.md).

**Status:** Scaffolded, not yet populated.

## Future Contents

- The full, ranked legal priority list (13 instruments, Law No. 22/2023/QH15 down to internal
  college regulations), each with: full citation, effective date, supersession history,
  summary of what it governs.
- Cross-reference table showing which articles of which instrument apply to which procurement
  scenario (package type × value range × fund source).
- Links to the source `.docx` documents in the repository-root `Legal/` folder.

## Explicit Non-Duplication Rule (Boundaries)

This folder is the **only** place the full ranked citation list is written out in complete
detail. `CONSTITUTION.md` states the rule ("always prefer newer"); the Knowledge Platform's
`legal` provider stores the same facts as structured `KnowledgeItem` records for machine
resolution. When populating this folder, source content from the Knowledge Platform's actual
data where possible rather than re-transcribing the source documents by hand a third time.

## Ownership

Owned by whoever maintains the legal corpus (the `legal` Knowledge Platform provider and the
source `.docx` files in repo-root `Legal/`) — this folder is a derived reference, never an
independent source of legal truth. Per [`../../KNOWLEDGE_BASE_EDITOR_GUIDE.md`](../../KNOWLEDGE_BASE_EDITOR_GUIDE.md).

## Update Policy

Additive per [`../../DOCUMENTATION_CHANGE_POLICY.md`](../../DOCUMENTATION_CHANGE_POLICY.md).
Update this folder whenever a new legal instrument is added to the corpus or an existing one is
superseded — cross-check against the `legal` provider's data at the same time, never let the
two drift.

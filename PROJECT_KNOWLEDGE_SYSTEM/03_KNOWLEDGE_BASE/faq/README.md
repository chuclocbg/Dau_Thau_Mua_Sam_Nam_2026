**Purpose:** Frequently asked questions — the practical, question-shaped entry point for users
who don't yet know which other Knowledge Base folder they need.

**Status:** Scaffolded, not yet populated.

## Future Contents

- Real questions collected from actual usage (not invented ahead of time — this folder should
  be populated from genuine recurring questions, not speculative ones).
- Each answer links out to the authoritative folder ([`legal/`](../legal/README.md),

- Once Phase X exists, this folder's questions are the natural seed set for the
  [Golden Question Regression methodology](../../01_PROJECT_DOCS/GOLDEN_QUESTION_METHODOLOGY.md)
  used in Phase X.8 (Evaluation).

[`GOLDEN_QUESTION_METHODOLOGY.md`](../../01_PROJECT_DOCS/GOLDEN_QUESTION_METHODOLOGY.md), not here.

## Ownership

yet, since no real usage exists — this folder remains empty until then, by design.

## Update Policy

Additive only, and only from genuine recurring questions — never speculative ones (per this
folder's own Purpose statement above).
